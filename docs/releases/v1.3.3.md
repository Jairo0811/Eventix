# Eventix v1.3.3 — Verificación escolar por identidad y tema visual unificado

## Estado

Release de mantenimiento funcional de la línea v1.3.x. Corrige el modelo de
promociones escolares para reflejar que el padrón institucional contiene
nombres y metadatos escolares, no cédulas. También consolida la interfaz en una
única identidad visual híbrida.

Los pagos comerciales reales, webhooks y payouts automáticos continúan
reservados para v1.4.0.

## Cambios principales

### Padrón escolar sin cédulas

- el CSV del padrón utiliza `full_name,student_code,source_reference`;
- las entidades y vistas de miembros dejan de persistir o mostrar cédulas;
- Flyway V25 elimina `national_id_lookup` y `national_id_last4` de
  `promotion_members`;
- el padrón conserva nombre, código estudiantil opcional, referencia y estado;
- se mantiene deduplicación de filas mediante nombre normalizado y código.

### Verificación basada en identidad

El flujo queda definido como:

`cédula → proveedor de identidad → nombre oficial → padrón → elegibilidad`.

- `CitizenIdentityProvider` desacopla el dominio escolar de cualquier proveedor
  externo concreto;
- el nombre del perfil de Eventix ya no participa en la decisión de
  elegibilidad;
- una coincidencia exacta y única del nombre normalizado produce `VERIFIED`;
- ausencia del nombre en el padrón produce `NOT_FOUND`;
- múltiples coincidencias exactas producen `MANUAL_REVIEW`;
- identidad inexistente y proveedor no disponible tienen estados diferenciados;
- sin proveedor productivo configurado, Eventix falla de forma cerrada.

### Privacidad y auditoría

- la cédula se usa únicamente durante la consulta de identidad;
- los intentos conservan HMAC-SHA-256 y últimos cuatro dígitos para trazabilidad;
- la cédula completa no forma parte del padrón ni de las vistas de
  verificaciones;
- V25 amplía los resultados de auditoría con `IDENTITY_NOT_FOUND` y
  `PROVIDER_UNAVAILABLE`.

### Desarrollo local

- `EVENTIX_IDENTITY_DEV_RECORDS` permite configurar identidades ficticias con
  el perfil `dev`;
- el formato es `cedula=Nombre Completo;cedula=Nombre Completo`;
- esta variable es exclusivamente para pruebas y no debe contener datos reales
  en el repositorio;
- Docker Compose propaga la variable al contenedor de la aplicación.

### UI / UX

- desaparece el selector claro/oscuro/sistema;
- se elimina la persistencia de preferencias de tema y `theme.js`;
- Eventix utiliza una única identidad visual: navegación oscura y superficies
  de trabajo claras;
- el flujo de verificación explica que la cédula resuelve una identidad y que
  el padrón se contrasta por nombre.

## Compatibilidad

- Java 21
- Spring Boot 3.5.x
- Microsoft SQL Server 2022
- Docker / Docker Compose
- Flyway V25
