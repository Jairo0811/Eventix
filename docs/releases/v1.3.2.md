# Eventix v1.3.2 — Promociones escolares de extremo a extremo

## Estado

Release de mantenimiento funcional de la línea v1.3.x. Completa la experiencia
operativa de promociones escolares y enlaza la verificación escolar con el
sistema genérico de Eligibility & Benefits utilizado por el checkout.

Los pagos comerciales reales, webhooks y payouts automáticos continúan
reservados para v1.4.0.

## Cambios principales

### Promociones escolares

- administración de instituciones educativas y promociones;
- activación y desactivación controlada de instituciones y promociones;
- importación de padrones CSV con validación, checksum y deduplicación;
- plantilla CSV descargable con el encabezado esperado por el importador;
- historial de importaciones y consulta del padrón sin exponer la cédula
  completa;
- autoservicio para que usuarios `USER` verifiquen su promoción mediante
  cédula protegida con HMAC-SHA-256;
- revisión manual administrativa con aprobación, rechazo y revocación
  justificadas.

### Integración con Eligibility & Benefits

- los grupos `PROMOTION_MEMBER` pueden vincularse explícitamente con una
  promoción escolar;
- una verificación escolar `VERIFIED` sincroniza automáticamente la membresía
  correspondiente en `eligibility_memberships`;
- rechazar o revocar una verificación escolar revoca las membresías derivadas;
- el checkout reconoce correctamente descuentos, entrada gratuita, límites de
  compra, entradas exclusivas y acceso controlado derivados de una promoción;
- los grupos inactivos dejan de conceder acceso o beneficios.

### Base de datos

- Flyway `V24__link_school_promotions_to_eligibility_groups.sql` añade el vínculo
  entre `eligibility_groups` y `school_promotions`;
- índice específico para consultas por promoción activa;
- migración validada sobre Microsoft SQL Server 2022 mediante CI y Docker
  Compose.

### Seguridad y calidad

- la administración de padrones escolares queda restringida a
  `ADMINISTRATOR`;
- el servicio de importación valida también el rol del actor y no depende solo
  de la autorización del controller;
- invariantes de longitud y formato se refuerzan en las entidades de dominio;
- la cédula completa no se persiste como clave de consulta ni debe aparecer en
  logs o respuestas HTTP;
- nuevas pruebas cubren el puente promoción escolar → membresía → beneficios,
  la revocación y los permisos del importador.

### UI / UX

- navegación administrativa para promociones escolares;
- pantallas para instituciones, promociones, padrón e historial;
- pantalla de verificaciones para revisión administrativa;
- flujo `Mi promoción escolar` para usuarios finales;
- selector de promoción escolar al configurar grupos `PROMOTION_MEMBER`.

## Compatibilidad

- Java 21
- Spring Boot 3.5.x
- Microsoft SQL Server 2022
- Docker / Docker Compose
- Flyway V24
