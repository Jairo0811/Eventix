# Eventix v1.3.1 — Estabilización y distribución verificable

## Estado

Release de mantenimiento de la línea v1.3.x. No introduce una pasarela de
pago comercial: los pagos productivos y payouts continúan reservados para
v1.4.0.

## Cambios principales

### Configuración segura

- `EVENTIX_ELIGIBILITY_HMAC_SECRET` queda documentado, enlazado en Spring y
  transferido explícitamente por Docker Compose.
- Docker Compose rechaza el arranque cuando falta el secreto de elegibilidad.
- CI genera un secreto HMAC efímero de 256 bits.
- `NationalIdLookupService` rechaza secretos menores de 32 bytes.
- Se documenta que la clave debe permanecer estable para conservar las huellas
  de los padrones importados.

### Calidad

- pruebas directas del checkout del comprador;
- cobertura de compra gratuita por beneficio de elegibilidad;
- contrato automatizado para la configuración HMAC de aplicación, Compose y
  CI;
- versión de Actuator derivada de Maven.

### Release engineering

- la publicación espera el éxito de `Eventix CI` en `main`;
- reejecuciones de una versión publicada son idempotentes;
- el JAR verificado y el SBOM del mismo commit se adjuntan a la release;
- publicación manual conserva una ruta controlada de respaldo.

### Documentación y gobierno

- README, changelog, manuales, modelo ER y casos de uso sincronizados con
  v1.3.x;
- licencia MIT añadida;
- roadmap separado entre funcionalidades entregadas y trabajo productivo
  posterior.

## Compatibilidad

- Java 21
- Spring Boot 3.5.x
- Microsoft SQL Server 2022
- Docker / Docker Compose

## Próxima línea

v1.4.0 integrará un gateway comercial real, webhooks, reconciliación,
reembolsos externos y payouts a organizadores.
