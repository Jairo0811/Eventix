# Eventix v1.3.4

Patch de consistencia visual y taxonomía para el Home y los eventos de promociones escolares.

## Cambios principales

- El Home deja de cargar el antiguo `theme.js` y elimina definitivamente el selector claro/oscuro/sistema.
- Eventix mantiene una única identidad visual híbrida: navegación y superficies de énfasis oscuras, con áreas de trabajo claras.
- Las cuatro capacidades de la sección “Plataforma integral” se rediseñan como tarjetas oscuras/teal con acentos verdes para integrarse con la identidad visual de Eventix.
- Se agrega mediante Flyway V26 la categoría activa `Promoción escolar` para graduaciones, reencuentros y actividades exclusivas de una promoción o generación escolar.

## Modelo funcional

La categoría `Promoción escolar` clasifica el evento, pero no concede ni restringe acceso por sí sola. La pertenencia a una promoción, los descuentos, la entrada gratuita, los límites y los tipos de entrada exclusivos continúan gestionándose mediante Elegibilidad & Beneficios.

## Base de datos

- Flyway V26: `V26__add_school_promotion_event_category.sql`.
- La inserción es idempotente y no depende de un identificador numérico fijo.
