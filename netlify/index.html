Estado del proyecto

Estamos preparando la apertura.

Esta página es una vista comercial estática. El catálogo con datos reales, las cuentas, las compras y las boletas operarán en el servidor Spring Boot, cuando su despliegue y las integraciones estén disponibles. Aquí no se procesan pagos ni se emiten entradas.
